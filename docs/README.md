# Format descriptions

`iTunesSD3gen.md` and `iTunesStats3gen.md` describe the iPod shuffle's play database and its play
statistics. They are copies of pages from the shuffle3db wiki (shuffle3db.wikispaces.com), which no
longer exists; earlier maintainers of this project saved them here so the descriptions would not be
lost. The original pages can still be seen
[via the Wayback Machine](https://web.archive.org/web/20131016014401/http://shuffle3db.wikispaces.com/iTunesSD3gen).

The wiki never stated a licence for its pages. They belong to their original authors, are not
covered by this project's licence (GPL-2.0-or-later), and are kept for reference only.
